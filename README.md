# Processamento de Dados com Python 🚀

Repositório utilitário em Python com Pandas para manipulação eficiente de arquivos CSV e Excel, focado em validação e exploração de dados.

## 📋 Funcionalidades
- Leitura e carregamento automatizado de arquivos `.csv` e `.xlsx`.
- Tratamento e validação inicial de dados com Pandas.
- Exibição de resumo e primeiras linhas do conjunto de dados no console.

## 🛠️ Tecnologias Utilizadas
- **Python** (versão 3.x)
- **Pandas** (manipulação e análise de dados)
